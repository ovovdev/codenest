## 第二点：激活不难，难的是没人告诉你卡在 UDP

人在英国激活没什么可讲的，插卡就能用。人在**国内**激活，靠的是 WiFi Calling，而它藏着一个几乎没人提前告诉你的前提。

先说结论，就两步：

1️⃣ 电脑走一条**支持 UDP 的英国线路**，开热点；
2️⃣ 手机连上热点，看到 **EE WiFiCall**，拨 **888**，收到激活短信，结束。

为什么大多数人卡住？WiFi Calling 走 IPsec 通道，靠 **UDP 500 和 4500** 两个端口。大多数普通节点能上网、能看视频，但 UDP 不通——于是手机这边永远转圈，重启多少次都没用。**错的不是卡，是线路。**

电脑配置这步可以偷懒，把下面这段整段复制、发给你的 AI 助手，让它去配：

```text
我有一条支持 UDP 的英国节点线路。请帮我把这台电脑配置好，让它通过这条英国线路上网，并开一个 Wi-Fi 热点供手机连接，用来激活一张英国电话卡（走 WiFi Calling）。

要求：
1. 先记下我现在的代理/网络设置，方便事后恢复。
2. 选英国节点，开启 TUN 模式和全局模式，并实际验证：出口 IP 在英国；UDP 能收到回复（WiFi Calling 要走 UDP 500/4500）。
3. 把这条连接共享成 Wi-Fi 热点，告诉我热点名和密码，保持开启，等我通知再关。
4. 等我明确说“可以恢复了”，再关闭热点、恢复原来的设置。
```

手机端就四件事：

1. 开飞行模式，再单独开 Wi-Fi，连上电脑热点。
2. 先用浏览器查一下自己的 IP，**显示在英国再往下走**，不是英国就回去查电脑那步。
3. 插卡，给这张卡打开「WiFi 通话」，等状态栏出现 **EE WiFiCall**。
4. 拨 **888**，听到欢迎语音挂断，激活短信随后到。查余额给 888 发 BAL。

卡住时对着查：出口是不是英国 → 线路 UDP 通不通（最高频）→ 连的是不是电脑热点 → EE WiFiCall 出没出。四条都对还不行，找官方客服 help@ctexcel.com，中文的，别找收费代激活。
